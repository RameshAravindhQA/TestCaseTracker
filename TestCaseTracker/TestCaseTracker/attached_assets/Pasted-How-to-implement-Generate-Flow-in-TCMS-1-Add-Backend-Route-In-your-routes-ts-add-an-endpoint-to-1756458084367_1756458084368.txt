How to implement “Generate Flow” in TCMS
1. Add Backend Route

In your routes.ts, add an endpoint to fetch test cases and return a diagram definition (e.g., in Mermaid.js or Cytoscape.js format).

// routes.ts
import express from "express";
const router = express.Router();

// Example: Generate flow for project test cases
router.post("/flow-diagrams/generate/:projectId", async (req, res) => {
  try {
    const { projectId } = req.params;

    // Fetch test cases for project (replace with DB call)
    const testCases = [
      { id: "BEG-TC-001", feature: "User Registration", objective: "Valid Data" },
      { id: "BEG-TC-002", feature: "User Registration", objective: "Empty Fields" },
      { id: "BEG-TC-003", feature: "User Registration", objective: "Invalid Email" },
    ];

    // Build a simple Mermaid graph definition
    let mermaidDef = "graph TD;\n";
    testCases.forEach((tc, i) => {
      mermaidDef += `TC${i}["${tc.id}: ${tc.objective}"];\n`;
      if (i > 0) mermaidDef += `TC${i-1} --> TC${i};\n`;
    });

    res.json({
      success: true,
      diagram: mermaidDef
    });

  } catch (error) {
    res.status(500).json({ success: false, error: error.message });
  }
});

export default router;

2. Frontend Integration

In your React/Next.js frontend:

Add a button “Generate Flow” (already visible in your screenshot).

On click → Call /flow-diagrams/generate/:projectId.

Use a Mermaid renderer or Cytoscape.js to render the diagram.

Example with Mermaid:

import React, { useState } from "react";
import mermaid from "mermaid";

const FlowDiagram = ({ projectId }) => {
  const [diagram, setDiagram] = useState("");

  const generateFlow = async () => {
    const res = await fetch(`/api/flow-diagrams/generate/${projectId}`, { method: "POST" });
    const data = await res.json();
    if (data.success) {
      setDiagram(data.diagram);
    }
  };

  return (
    <div>
      <button onClick={generateFlow} className="p-2 bg-blue-500 text-white rounded">
        Generate Flow
      </button>

      {diagram && (
        <div
          className="mt-4"
          dangerouslySetInnerHTML={{ __html: mermaid.render("diagramDiv", diagram) }}
        />
      )}
    </div>
  );
};

export default FlowDiagram;

3. Output Example

For your test case table (User Registration test cases), it would generate a Mermaid diagram like:

graph TD;
  TC0["BEG-TC-001: Valid Data"];
  TC1["BEG-TC-002: Empty Fields"];
  TC2["BEG-TC-003: Invalid Email"];
  TC3["BEG-TC-004: Short Password"];
  TC0 --> TC1;
  TC1 --> TC2;
  TC2 --> TC3;


Which shows a flow like:

👉 Valid Data → Empty Fields → Invalid Email → Short Password

4. Alternative (Mind Map Style)

If you want the exact mind map style (like your second image), then Cytoscape.js is better because Mermaid is mostly sequential/graph.
With Cytoscape you can easily do:

elements: [
  { data: { id: 'root', label: 'User Registration' } },
  { data: { id: 'tc1', label: 'Valid Data' } },
  { data: { id: 'tc2', label: 'Empty Fields' } },
  { data: { id: 'tc3', label: 'Invalid Email' } },
  { data: { source: 'root', target: 'tc1' } },
  { data: { source: 'root', target: 'tc2' } },
  { data: { source: 'root', target: 'tc3' } },
]


That gives you root node → test cases branching like your screenshot.
