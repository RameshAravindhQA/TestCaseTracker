Requirement Title

 Landing & Login Experience

Author

 Chandrachur Palchaudhuri

Date Created

9 Jun 2025

Date Last Updated

9 Jun 2025

Overview

Redesign of the landing page and login flow for the Aspire Ikoo platform, aligned with the branding and user journey objectives. Remove open registration and introduce controlled login.

 

Problem Statement

Current landing page is not user-friendly, lacks product positioning, and includes unnecessary self-registration options

 

Objective / Goals

Remove open registration

Retain login + password recovery

Reflect positioning via four buckets: Create, Compare, Learn, Connect

 

Scope

In Scope: Login, password reset, landing UI, positioning blocks.

Out of Scope: OTP login (deferred, enable depending of effort)

 

User stories / Use cases

As a user, I want to sign in securely using credentials provided by admin.

As a user, I want to understand the product pillars as I land on the platform.

 

Functional Requirements

Disable sign-up

Login form with email + password

Retain forgot password (email-based recovery)

Display 4 positioning buckets with explanatory text

 

Non-Functional Requirements (As applicable)

Secure login with hashed credentials

 

Design & UI/UX

Clean, minimalist UI with accessible text

Wireframes pending (to be attached)

 

Dependencies

Admin user onboarding flow

Email service for password reset

 

Assumptions

All users will be created through Admin user onboarding flow. 

 

Acceptance Criterion

User cannot self-register

Forgot password triggers email

Positioning text visible on landing

 

Risks & Mitigations

Unknown as of now
